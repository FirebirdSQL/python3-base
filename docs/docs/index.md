# The Firebird Base library for Python

The `firebird-base` package provides common Python 3 modules used by Firebird Project
in various development projects. However, these modules have general applicability outside
the scope of development for Firebird RDBMS.

## Installation

```console
pip install firebird-base
```

!!! note
    Requires Python 3.11+
!!! tip
    You can download docset for [Dash](https://kapeli.com/dash) (MacOS) or
    [Zeal](https://zealdocs.org/) (Windows / Linux) documentation
    readers from [releases](https://github.com/FirebirdSQL/python3-base/releases) at github.

[Firebird Project]: http://www.firebirdsql.org
